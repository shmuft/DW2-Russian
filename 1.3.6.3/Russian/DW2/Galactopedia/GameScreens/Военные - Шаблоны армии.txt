Шаблоны армий позволяют определить относительный состав типов войск. Шаблоны армий используются флотами и колониями для указания количества каждого типа войск, которое у них должно быть.

[H3]Типы шаблонов армий[/H3]
Существует 4 основных типа шаблона армии:
[ULI]Вторжение: назначено флотам для определения того, какие войска следует использовать при вторжении в колонии противника. Обычно сюда входят многочисленные бронетанковые войска, некоторые подразделения спецназа, пехота и титаны (если доступны)[/ULI]
[ULI]Оборона ключевых колоний: назначается для ключевых колоний (таких как ваша столица), чтобы определить, какие войска должны использоваться для защиты колонии от вторгающихся вражеских войск. Обычно сюда входят все типы войск, но особенно большое количество пехоты и планетарных оборонительных подразделений.[/ULI]
[ULI]Оборона приграничных колоний: назначается уязвимым приграничным колониям для определения того, какие войска следует использовать для защиты колонии от вторгающихся вражеских войск. Обычно это включает большое количество пехоты и некоторые планетарные оборонительные подразделения.[/ULI]
[ULI]Стандартная армия обороны колонии: назначается всем остальным колониям для определения того, какие войска должны использоваться для защиты колонии от вторгающихся вражеских войск. Обычно в её состав входит большое количество пехоты.[/ULI]

Для каждого типа существует шаблон по умолчанию, но вы можете изменить их или создать дополнительные шаблоны, соответствующие вашим потребностям.

[H3]Назначение шаблонов армий[/H3]
Вы можете выбрать шаблон армии для колонии, выделив эту колонию и нажав кнопки «Настройка автоматизации колонии» > «Шаблон армии» на панели выбора. После этого появится список всех доступных шаблонов армии. Выберите нужный шаблон, кликнув по нему в списке. Затем колония попытается набрать защитные войска в соответствии с пропорциями, указанными в шаблоне.

Вы можете выбрать шаблон армии для флота, выделив флот и нажав кнопку «Шаблон армии» на панели выбора. Появится список всех доступных шаблонов армии. Выберите нужный шаблон, щелкнув по нему в списке. После этого флот попытается загрузить войска в соответствии с пропорциями, указанными в шаблоне.
