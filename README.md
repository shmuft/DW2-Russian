Данный мод переводит игру на русский язык.
Для старой ручной установки в свойствах игры укажите `--font RussianFont`.
Скорее всего есть недопереведённые тексты. Если вы найдёте - сообщите. Кроме стартового окна. Там я не знаю как исправить

Использованный шрифт JetBrains Mono. https://www.jetbrains.com/ru-ru/lp/mono/

Старый способ ручной установки: в директорию data установленной игры нужно скопировать всё содержимое.
Перед этим удалив папку galactopedia

Для перевода использовались LLM Qwen3.5-35b-a3b Q6_K, LLM Qwen3.6-35b-a3b Q6_K.
Для уточнения перевода заголовков исследований Google Gemeni, Github Copilot.

## Сборка мода для DW2 Mod Launcher

```powershell
.\build_release.ps1 -Version 1.3.7.9 -ModLoader
```

Команда создаёт папку локального мода и ZIP в `build\`. XML переводится в минимальные патчи,
содержащие только изменённые переведённые поля. Для `.txt` сохраняется полный английский файл,
а строки с готовым переводом подменяются русскими: загрузчик использует эти файлы целиком.
