Данный мод переводит игру на русский язык. Перевод распространяется в формате мода
для DW2 Mod Launcher. Если нужен старый вариант для ручной установки, его архив
входит в релиз в директории `old_mod`.

Скорее всего, в игре остались непереведённые тексты. Если вы найдёте такие,
сообщите об этом. Исключение — стартовое окно, перевод которого пока не исправлен.

Для перевода использовались LLM Qwen3.5-35b-a3b Q6_K, LLM Qwen3.6-35b-a3b Q6_K.
Для уточнения перевода заголовков исследований Google Gemeni, Github Copilot.

## Сборка релиза

```powershell
.\build_release.ps1 -Version 1.3.8.0
```

Команда создаёт единый архив в `releases\`. Файлы мода для DW2 Mod Launcher
находятся в корне архива; рядом лежат `README.txt` и папка `old_mod` с архивом
старого варианта для ручной установки. XML нового мода содержит минимальные
патчи только переведённых элементов. Каталоги `Galactopedia` и `dialog`
копируются в новый мод целиком из русского перевода. Для остальных `.txt`
сохраняется английская основа и подменяются строки, для которых есть перевод.
