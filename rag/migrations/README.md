# Миграции базы данных RAG

## Структура

Миграции хранятся в этой директории в формате `NNN_description.sql`.
Номер определяет порядок применения.

## Версии

| Файл | Версия | Описание |
|------|--------|----------|
| `001_initial.sql` | 1 | Инициализация: таблица `translations`, индексы, представления |
| `002_en_search_and_indexes.sql` | 2 | Англоязычный поиск, индексы по файлам/категориям/версиям |

## Как добавить миграцию

1. Создайте файл `NNN_name.sql` в этой директории
2. SQL должен быть **идемпотентным** (безопасно повторять)
3. Используйте `CREATE TABLE IF NOT EXISTS`, `CREATE INDEX IF NOT EXISTS`
4. Для изменений: `ALTER TABLE ... ADD COLUMN IF NOT EXISTS`
5. Не используйте `DROP TABLE` без проверки — только `IF EXISTS`

## Применение

```bash
# Применить все недостающие миграции
python rag/rag.py migrate

# Применить до конкретной версии
python rag/rag.py migrate --target 2

# Показать текущую версию
python rag/rag.py migrate --status
```
